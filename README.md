# trekking

## Ficha operativa en PDF

Desde la gestión de recorridos se puede generar una ficha PDF para el
recorrido seleccionado. La ficha contiene los datos de la ruta, checkpoints,
participantes y equipamiento requerido disponibles al exportarla. Incluye
Open Sans embebida para mantener los caracteres en español al abrirla sin
conexión.

Los adjuntos de fichas médicas se guardan como archivos PDF en la base de
datos, pero esta aplicación no interpreta su contenido: no se copian a la
ficha operativa. Si se necesitan durante una salida, deben consultarse por
separado siguiendo el protocolo de privacidad definido por la organización.
